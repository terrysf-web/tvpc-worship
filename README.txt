TVPC Worship Stable Viewer v3 - LIVE

이 파일은 방금 Ainos에서 정상 테스트된 안정 구조를 tvpc-worship 운영 주소용으로 바꾼 버전입니다.

적용:
1. ZIP 압축 풀기
2. 안의 모든 파일을 tvpc-worship repo root에 업로드/교체
   - index.html
   - manifest.json
   - icon files
3. GitHub Pages 배포 완료 후 아래 주소로 새로 열기:
   https://terrysf-web.github.io/tvpc-worship/index.html?v=worship-stable-v3

확인:
화면 왼쪽 위에
TVPC-WORSHIP STABLE V3 LOADED
빨간 배지가 보여야 새 버전이 맞습니다.

중요:
iPad 홈화면 앱은 예전 캐시가 남을 수 있습니다.
문제가 있으면 홈화면 아이콘 삭제 후 위 주소로 다시 열고 홈화면에 추가하세요.
